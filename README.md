# Imperial Barber

Aplicação web full-stack para uma barbearia premium, com foco em experiência digital, agendamento online e gestão administrativa.

## ✨ Visão geral

A Imperial Barber foi desenvolvida como um projeto de portfólio com uma proposta visual premium e uma experiência completa para clientes e administradores.

O projeto inclui:

- Site institucional
- Sistema de agendamento
- Painel administrativo
- Gestão de serviços
- Gestão de profissionais
- Agenda de atendimentos
- Controle de status dos agendamentos
- Métricas e faturamento
- Autenticação
- Interface responsiva

## 🧩 Principais funcionalidades

### Cliente
- Visualizar serviços
- Escolher profissional
- Selecionar data e horário
- Realizar agendamento
- Receber confirmação

### Administrador
- Visualizar agendamentos do dia
- Confirmar, remarcar e cancelar atendimentos
- Gerenciar serviços
- Gerenciar profissionais
- Consultar faturamento
- Acompanhar métricas da barbearia

## 🛠 Tecnologias

- React
- TypeScript
- Next.js / Vinext
- Tailwind CSS
- Drizzle ORM
- Banco de dados
- Autenticação
- Git & GitHub

## 🎨 Design

A identidade visual da Imperial Barber foi construída com uma estética masculina, premium e editorial.

Paleta baseada em:

- Preto
- Grafite
- Azul-marinho
- Off-white
- Azul de destaque

O objetivo foi evitar a estética genérica de interfaces geradas por IA, priorizando tipografia, fotografia, composição e hierarquia visual.
